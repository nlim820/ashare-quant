# 双均线 · 240 趋势过滤「安检门」动画网页

一个**独立可演示**的网页：输入任意 A 股 / ETF 代码，现场拉取真实行情，用唯美动画演示
**双均线金叉买入、死叉清仓**，以及 **240 日均线门控式趋势过滤（「安检门」）**如何拦掉
下跌趋势里的假金叉。

> 这是 `ashare_quant` 主项目的**独立演示模块**，但**复用主项目的数据层**
> （`../src/data_utils.get_price`）：即多源回退（东财→新浪→腾讯）、本地缓存、
> qfq/hfq 复权端到端透传——动画、Streamlit 网页、回测/样本外检验用的是**同一份数据**。

## 功能特性

- 🎯 **任意标的现场拉**：输入代码（如 `600519`、`300750`、`510300`）即可拉真实日线
- 🎬 **唯美动画**：深空渐变背景 + 柔光霓虹线条 + 平滑生长 + 信号涟漪脉冲
- 🚦 **安检门可视化**：长期趋势线（默认 MA240）实时显示「开放✓ / 拦截✕」
- 📊 **实时统计**：金叉通过 / 拦截 / 死叉 / 持仓占比，底部「持仓时间轴」一眼看穿
- 🔧 **可调参数**：快线、慢线、过滤线周期，安检门开关；改参数即时重播（不重新拉数据）
- 📱 **移动端友好**：纯 Canvas + 响应式，手机浏览器原生可跑

## 运行方式

需要：Python 3.9+，且已安装 `akshare`、`pandas`（即主项目环境，无需额外安装 Flask 等）。

### 方式一：一键启动（推荐，Windows 双击）

直接**双击 `anim/run.bat`** —— 它会自动启动后端，并在 1 秒后**自动弹出浏览器**打开演示页。
全程无需手动开终端、也无需手动开浏览器。要停止时，关掉弹出的黑色后端窗口即可。

> 若浏览器没有自动弹出，手动访问 **http://localhost:8765** 即可。

### 方式二：命令行启动

```bash
cd ashare_quant/anim
python server.py            # 默认 http://localhost:8765，并自动打开浏览器
# 不想自动开浏览器时：
python server.py --no-browser
# 自定义端口：
python server.py --port 9000
```

浏览器打开 **http://localhost:8765** ，输入代码点击「加载并播放」。

> 首次对某标的拉取会走 akshare 实时接口并写入 `../data/raw/*.csv` 缓存；之后离线也能秒开。
> 若东财被限流，后端自动回退新浪/腾讯；股票名称可能临时回退为代码（限流恢复后正常）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `server.py` | 零依赖轻量后端（标准库 `http.server`），`/api/quote` 调 `data_utils.get_price` 拉数据 |
| `index.html` | 前端 Canvas 动画 + 控制面板（完全自包含，无外部 CDN） |

## 与主项目的关系

- 数据层、缓存、复权口径、趋势过滤逻辑**完全一致**，保证「演示 = 回测 = 样本外检验」
- 主项目回测结论（双均线无稳定 alpha、趋势过滤控回撤但夏普未改善）在本动画中可被直观验证
- 可作为面试/分享时的「原理可视化」配菜，配合主项目 Streamlit 网页与简历项目经历使用

## 技术说明

- 后端仅用 Python 标准库（`http.server`），**零额外依赖**，易部署
- 前端纯原生 Canvas + JS，无任何第三方库 / CDN，可离线运行
- 均线（SMA）与信号（金叉/死叉/过滤判定）在前端计算，与后端回测口径一致
