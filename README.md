### 工程特性：限流自愈（数据获取容错）
公开行情接口（东方财富）对单 IP 有频率限制，频繁抓取会临时限流。`data_utils.py` 内置两层容错：
- **多源回退**：股票与基金的东方财富接口被限流时，自动切换新浪数据源并统一列名，下游逻辑无感。
- **本地缓存**：`get_price()` / `get_index()` 首次抓取后存 `data/raw/*.csv`（已被 `.gitignore` 忽略），同一「代码 + 区间」再次请求直接读缓存，从根本上避免重复联网触发限流。
> 注意：新浪 ETF 接口仅返回全量且不复权数据，兜底时与东方财富 qfq 有细微差异，仅作限流时的临时容错。
>
> **2026-11-03 修掉的一个真 bug（数据层）**：早期版本不看这个 `sina_noadj` 标记，把新浪回退的
> **不复权**数据直接写进了 `_qfq.csv` 缓存——文件名声称前复权、内容是原始价，而且读缓存时走的是
> 缓存分支、不再触发任何告警，属于「静默错」。实测 510300 旧种子与新浪不复权序列的比值恒为
> `1.000000`（漂移 0%），2020–2023 三年总收益 −15.67%，而真实含分红口径为 −12.00%，**少算 3.7pp**。
> 现在不复权的回退数据一律拒绝写盘（`data_utils._cache_writable`，有单测覆盖），三只 ETF 种子
> 已用腾讯源（支持 ETF 的 qfq/hfq）重新生成，并用「qfq/hfq 比值是否漂移」验证复权确实生效。

## Phase 2 成果：双均线策略回测 (Current)
- `src/data_utils.py` —— 抽离的公共数据层（取数 + 算均线），Phase 1/2 共用；按代码前缀自动识别 **A股个股 / 场内 ETF 基金**并切换数据源（东方财富股票/ETF 接口，**股票与基金限流均自动回退新浪**）。
- `src/phase2_backtest.py` —— 基于 `backtrader` 的 **MA5/MA20 双均线金叉死叉策略**回测：
  - 金叉买入、死叉清仓，`PercentSizer` 满仓、`commission` 万 5 手续费。
  - 输出三大量化指标（均按公式手动计算，并与 backtrader 内置分析器交叉验证）：
    **年化收益、夏普比率、最大回撤**。
  - 自动与「买入持有」对比，判断策略是否跑出超额。
  ```bash
  python src/phase2_backtest.py --symbol 600519  --start 20200101 --end 20231231   # A股个股
  python src/phase2_backtest.py --symbol 510300  --start 20200101 --end 20231231   # 场内 ETF 基金
  ```
- 示例结果（茅台 2020–2023，970 个交易日）：策略年化 **15.41%** / 夏普 0.80 / 回撤 **−19.53%**；
  买入持有年化 13.73% / 夏普 0.58 / 回撤 −47.04% —— 策略以更小回撤跑赢基准。
  （单标的单周期，结论需更多样本验证；数据源限流时会自动回退、复权口径略有差异，
  重跑可能有小数点级偏差，切勿当作投资建议。）
- **场内 ETF 三只对照（2020–2023，MA5/MA20，均为 970 个交易日的无预热偏移口径，与上方茅台示例一致）**：
  这是最能说明「这个策略是什么」的一组样本 —— ETF 没有个股黑天鹅、交易成本低、也不存在
  「一手买不起」的干扰，结论比个股干净。

  | 标的 | 策略年化 | 买入持有 | 策略回撤 | 买入持有回撤 | 交易次数 |
  |---|---|---|---|---|---|
  | 510300 沪深300ETF | −3.88% | −3.27% | −28.64% | −42.67% | 34 |
  | 510500 中证500ETF | −3.29% | +2.38% | −27.35% | −32.79% | 32 |
  | 159915 创业板ETF | +1.57% | +1.12% | −30.03% | −49.20% | 31 |

  **三只全部跑输买入持有（年化），但三只全部把回撤压低了 5.4–19.2pp** —— 与下面 20 只个股
  参数网格的结论完全一致：双均线的价值在控回撤，不在赚钱。ETF 样本比个股更能说明问题，
  因为它排除了「某只票恰好走成牛市趋势」的偶然性。
- `src/phase2_batch.py` —— **多股票批量回测**（覆盖 8 只跨行业大盘股）：
  - 统计"策略跑赢买入持有的胜率"与平均绩效，避免单标的幸存者偏差。
  - 8 只样本（2020–2023，含 2022 熊市）结果：**胜率 50%**；策略平均年化 **−2.83%** vs
    持有 −3.23%，平均夏普 **−0.10** vs 0.04，但**平均最大回撤 −37.10% vs 持有 −52.47%**
    —— 即收益端没有稳定优势（胜率仅半数、平均夏普反而更低），却把平均回撤压低了约 15pp
    （−37.10% vs −52.47%，此处为点估计、未做配对检验；"显著"留给 Phase 3 的配对检验用）。
  - 结论：双均线更像是"风险控制工具"而非"收益增强工具"，需更多样本/参数与
    不同市场环境下验证，切勿当作投资建议。
- `src/phase2_deepen.py` —— **Phase 2 深化**（更大样本 + 参数敏感性 + 显著性检验）：
  - 样本扩至 **20 只跨行业大盘股 × 8 组 (快/慢线) 参数网格**（2020–2023）。
  - 方法严谨：所有参数组在**统一评估窗口**（剔除最大慢线预热期）上比较，
    保证买入持有基准口径一致、跨参数可比。
  - 参数敏感性：胜率 **40%~75%**；慢线 ≤60 的组合平均超额为正（+2.27%~+3.95%），
    慢线=120 的组合全部转负（−1.1%~−1.7%）；
    **所有参数下策略平均最大回撤 −32.8%~−37.6%，明显低于买入持有（−51.4%）**
    （点估计差约 15pp；未做配对检验，故不写"显著"——全项目的显著性表述只出现在 Phase 3/7）。
  - 统计显著性：默认 MA5/20 超额年化均值 +2.27%，单样本 t 检验
    `t=1.20, p=0.231` → **无法拒绝"无超额收益"的原假设**（MA5/20 这一组经 BH 多重检验校正后
    **q=0.370**，更不显著；注意 BH 是对 8 组参数各算一个 q，最优组 (5,60) 的 q=0.303，见下节表格）。
  - 样本外验证：IS(2020–2021) 最优参数 MA10/20 的超额本身为 **−0.57%**（`p=0.870`），
    OOS(2022–2023) 同组合 **+2.34%**（`p=0.409`）——方向与"熊市保护"一致，但两段均不显著。
  - 结论：双均线策略**没有稳定的收益 alpha，核心价值是风险控制（压低回撤）**；
    该结论本身即体现回测的严谨性，而非过度拟合的"漂亮曲线"。

- `src/phase3_improve.py` —— **策略改进闭环（给双均线加"240 日均线趋势过滤"并做配对检验）**：
  - 动机：双均线在熊市里会在"下跌途中的小反弹"上反复出现假金叉被反复打脸。
    改进思路：**门控式**过滤——仅当 `收盘价 > 240 日均线`（长期趋势向上）时才允许金叉买入，
    **死叉清仓规则不变**（只改入场、不改出场），相当于给入场加一道"安检"。
  - 方法：20 只跨行业大盘股，**原版 vs 过滤版在完全相同的 240 天预热窗口**上配对比较
    （过滤线 240 天比慢线更长，评估窗口必须后移到 240，否则过滤线未就绪就开始比，结论失真）。
  - 结果（均值，2020–2023）：
    | 指标 | 原版 | 过滤版 | 读法 |
    |---|---|---|---|
    | 入场次数 | 29.4 | 10.7（过滤掉 64% 金叉） | 达到"少交易"目标 |
    | 持仓占比 | 43.6% | 18.9% | 大幅空仓，≈25pct 时间不在场 |
    | 最大回撤 | −35.47% | −27.90%（朴素配对 t `p=0.005`；**相关性修正后 `p=0.213`，不显著**） | 方向性改善 |
    | 年化收益 | −5.14% | −5.42%（`p=0.880`，无改善） | 非"收益增强" |
    | 夏普比率 | −0.21 | −0.46 | 风险收益比反而变差 |
  - **显著性为什么要打折**（`src/phase7_robust_se.py`）：20 只 A 股同涨同跌，
    策略日收益平均相关系数 **ρ̄=0.179**，按 n_eff = n/(1+(n−1)ρ̄) 折算
    **等效独立样本只有约 4.5 只**，配对 t 的标准误被低估约 2.1 倍。
    （p 值一律按 **t 分布**取，n=20 时 df=19；正态近似在这么小的样本下会低估 p，
    例如 t=3.18 时正态给出 0.0015、t(19) 真值 0.0049。）
    | 检验口径 | Δ回撤 p 值 | 结论 |
    |---|---|---|
    | A 朴素配对 t（原口径，t=3.18，df=19） | 0.005 | 显著 |
    | B 有效样本量折算（t=1.51，df≈3.5） | 0.213 | 不显著 |
    | C 等权组合 + 分块 bootstrap（2000 次，块长 20 日） | 0.108 | 不显著 |
  - **诚实结论（不自我粉饰）**：趋势过滤在**点估计上**压低了回撤（个股均值 +7.57pp、
    组合层面 +3.74pp）、减少了交易，但：
    ① 持仓占比从 43.6% 骤降到 18.9%，回撤改善很大程度来自"在场时间变短"而非信号更聪明；
    ② **修正横截面相关性后不再显著**——20 只票不是 20 个独立试验，只能称"方向性证据"；
    ③ 夏普反而变差——过滤是"钝器"，既砍掉下跌假金叉，也错失上行金叉，"少冒险"≠"更会冒险"；
    ④ 与 Phase 2 自洽：双均线的价值在控回撤、不在增厚 alpha，趋势过滤把这点推到极致，
    但它用"长期空仓"换来的，并非免费午餐。这一步演示了完整的"假设→实现→回测→证伪→自我修正"闭环。

### Phase 4 成果：样本外检验（OOS）—— 用 2024–2026 全新数据验证结论

- `src/phase4_oos.py` —— 以 **2024–2026 这段从未参与任何调参的真实新数据**作样本外检验：
  - **IS（样本内）= 2020–2023**（与简历/Phase 2/3 完全一致，不复算结论，仅复述核对）；
  - **OOS（样本外）= 2024–2026**，参数**完全沿用 IS（MA5/20 + 可选 MA240 趋势过滤），不做任何重新调参**——这是真 OOS 的灵魂。
  - **历史预热**：OOS 用 2020–2026 全量喂策略（均线从 2020 就绪），但评估窗口与指数基准仅取 2024-01-01 起；2020–2023 只作均线预热与持仓延续，不计入 OOS 收益，模拟"带训练期参数直接应用到新数据"的真实场景。
  - **评估窗口统一**：IS 与 Phase 3/6/7/8 一样用 `warmup=240`（从 2020-12-29 起算）。
    这一条是 2026-11-03 修订的——旧版用 `warmup=None`（970 天），造成两个问题：
    ① 同一件事在 README 里出现两个数（Phase 3 个股均值 +7.57pp vs 本节旧 IS +9.27pp）；
    ② **原版与过滤版窗口不同**（原版 970 天、过滤版因 MA240 就绪被自动缩到 730 天），
    两者相减得到的"过滤让年化 −7pp"是窗口差异造成的假象，同窗口配对实为 −0.28pp。
  - ⚠️ 因此本节 IS 的绝对值（−5.14%）**不等于**网页/Phase 2 默认口径的茅台数字（10.94%），
    后者是 970 天口径。两个口径都对，只是回答的问题不同：970 天=「这段数据上策略表现如何」，
    730 天=「和过滤版在同一窗口上谁更好」。详见文末「评估窗口口径说明」。
- 20 只跨行业大盘股，原版 / 趋势过滤版 各在 IS、OOS 两组下的配对对比（均命中本地缓存，离线可跑）。

  **结果（2020–2023 IS → 2024–2026 OOS，20 只均值）：**

  | 指标 | IS 原版 | OOS 原版 | OOS 对照（同期买入持有） |
  |---|---|---|---|
  | 年化收益 | −5.14% | +4.49% | （大盘股反弹，行情本身更友好） |
  | 最大回撤 | −35.47% | **−24.89%** | 同期 BH **−33.16%** |
  | 夏普比率 | −0.21 | 0.31 | — |
  | OOS 跑赢 BH 比例 | — | **6/20（30%）** | — |
  | OOS 回撤 < BH 比例 | — | **15/20（75%）** | — |

  趋势过滤版：OOS 回撤仍改善 **+4.4pp**（IS +7.57pp），持仓占比 30%，但夏普仅 0.03——"用长期空仓换回撤"的机制在 OOS 依然有效，风险收益比未因新数据变好。

- **诚实结论（不自我粉饰）**：
  ① OOS 跑赢买入持有仅 30%，接近随机一半——双均线在完全未见过的数据上没有"挑时段"的超能力，"无稳定 alpha"结论稳健；
  ② 但"控回撤"特征在 OOS 反而更强（75% 标的回撤小于买入持有），印证 Phase 2"卖保险不卖收益"的判断；
  ③ 必须澄清：OOS 均值年化转正主要是**2024–2026 大盘股反弹的行情差异**，不是策略变强——判断应看"跑赢 BH 比例 / 控回撤比例"而非绝对数字；
  ④ 综上，Phase 2/3 结论在独立新数据上稳健，**比一条漂亮曲线更有含金量：结论不是过拟合挑出来的**。
  - 网页演示：把侧栏「结束日期」从 `20231231` 改为 `20261101` 即可查看 2024–2026 样本外行情与回测（本地秒开，Cloud 现场取数）。

### 评估窗口口径说明（为什么同一个茅台有两个数）

> 这是本项目最容易把人绕晕的地方，也是我自查时抓到的一个真问题（2026-11-03 修订）。
> 一句话：**所有回测都从 2020-01-01 拉数据，但"从哪天开始算收益"不同。**

慢线越长、预热越久，"策略可交易的起点"越靠后。如果策略从第 240 天才开始交易，
而买入持有从第 1 天就开始算，两者的年化就不是同一段时间——直接用年化相减，
量到的是"窗口差异"，不是"策略优劣"。所以本项目统一用 `warmup=N` 把两侧截到
**同一个起点**；不同脚本为了让不同参数可比，取了不同的 N。

| 脚本 / 场景 | 评估起点 | 交易日 | 该口径下的标志性数字 |
|---|---|---|---|
| `phase2_backtest`（网页默认、简历） | 2020-01-02，`warmup=None` | 970 | 茅台年化 **15.41%**、夏普 0.80、回撤 −19.53% |
| `phase2_batch`（8 只） | 2020-01-02 | 970 | −2.83% vs 持有 −3.23%，胜率 50% |
| `phase2_deepen`（20 只 × 8 组参数） | 第 120 日（最大慢线） | 850 | 平均超额 **+2.27%**，`t=1.20, p=0.231` |
| `phase3/6/7/8`（20 只配对实验） | 第 240 日（过滤线） | 730 | 回撤 −35.47%→−27.90%，Δ**+7.57pp** |
| `phase4` IS | 第 240 日（与上一行同口径） | 730 | IS 均值 −5.14% / −35.47% |
| `phase4` OOS | 2024-01-01（`eval_start`） | 683 | +4.49%、跑赢 BH 6/20、控回撤 15/20 |
| `phase5` IS / OOS | 分别为第 240 日 / 2024-01-01 | 730 / 683 | 组合 α 1.60%（`p=0.674`）/ 1.06%（`p=0.780`） |

**读法（三条规则）**：

1. **同一行内可比，跨行不可比。** 15.41%（970 天）和 10.94%（730 天）是同一只茅台在两个
   窗口上的年化，都真实，但不该并排说"策略从 15% 掉到 11%"——那是换窗口，不是策略变差。
2. **只有 Δ（过滤版 − 原版）必须在同一窗口内配对**，否则结论是假的。Phase 4 旧版的
   "过滤让年化 −7pp"就是这个错误的产物（原版 970 天 vs 过滤版 730 天），同窗口实为 **−0.28pp**。
3. **判断策略好坏看 Δ 和比例（跑赢 BH 几只、控回撤几只），不要看绝对年化。** 绝对年化
   主要反映区间行情：2020–2023 是熊市，20 只策略平均 −5.14%；2024–2026 反弹，同一策略 +4.49%。

### Phase 2 方法论说明：这条回测曲线凭什么可信

> 这一节写给"不看代码、只看结论"的读者（面试老师 / 导师）。
> 它讲的不是"我跑了什么策略"，而是**我怎么判断这条曲线是真的，还是回测幻觉**。
> 下文数字均可由 `python src/phase2_deepen.py` 复现（数据源限流时会自动回退新浪，复权口径差异可能带来小数点级偏差）。

#### 1. 先把问题写成可证伪的形式
原假设 **H₀：双均线择时相对买入持有没有稳定的年化超额收益**。

| 检验 | 结果 | 读法 |
|---|---|---|
| 默认参数 MA5/20 | 平均超额年化 **+2.27%**，`t=1.20, p=0.231` | 无法拒绝 H₀ |
| 8 组参数 BH-FDR 校正 | 8 组**各得一个** q 值（同一批校正、逐组不同）：默认 MA5/20 `p=0.231`→**`q=0.370`**；最优 (5,60) `p=0.063`→**`q=0.303`** | 挑出来的"最优"也不显著 |
| 样本外 walk-forward | IS 最优 MA10/20 超额 **−0.57%**（`p=0.870`）→ OOS **+2.34%**（`p=0.409`） | 符号与"熊市保护"一致，但两段都不显著 |

→ 于是结论只能写成：**没有稳定收益 alpha**；而不是"我的策略年化 X%"。

#### 2. 回测最容易骗人的六个地方，以及我分别怎么堵

| 自欺陷阱 | 典型表现 | 本项目的处理 |
|---|---|---|
| 单标的、单周期 | 挑一只走运的股票，曲线很漂亮 | 20 只跨行业大盘股（消费/金融/医药/能源/地产/公用/科技），同区间比较 |
| 参数挑完再报 p 值（data snooping） | 8 组里挑最好的一组做检验，p 值必然偏小 | 对 8 个原始 p 值一次性做 Benjamini–Hochberg FDR 校正，**每组各得一个 q 值**，报 q 而非 p |
| 样本内拟合 | 用同一段数据既选参又验证 | walk-forward：IS 选参 → OOS 只做检验，看衰减与符号是否反转 |
| 基准口径漂移 | 慢线越长，策略可交易起点越晚；买入持有却从第一天算，跨参数不可比 | `warmup=120`：策略与基准都截到第 120 个交易日，**完全同一窗口** |
| 只跟自己比、不跟市场比 | 跑赢个股 ≠ 有 alpha，可能只是承担了更多 Beta | 沪深300 基准；`app.py`/`phase2` 给 **CAPM 回归截距 + Newey-West 稳健 t/p**（近似口径 `年化 − β×指数年化` 仅作对照，不单独引用） |
| 零成本、指标自说自话 | 忽略佣金；指标公式无人核对 | 单边万 5 佣金、95% 仓位；Phase 6 另做真实成本检验；年化/夏普/回撤**手算 + backtrader 分析器交叉验证**；33 项单元测试锁口径 |

#### 3. 三个指标的口径（被追问要能当场推）
- 年化收益 `(1+总收益)^(252/n) − 1`
- 夏普比率 `日均收益 / 日收益标准差 × √252`（无风险利率取 0，A股常用近似）
- 最大回撤 `min(净值 / 历史峰值 − 1)`，回答"最惨会亏多少"

#### 4. 真正的发现：价值在回撤，不在收益
8 组参数下，策略平均最大回撤稳定落在 **−32.8% ~ −37.6%**，同期买入持有 **−51.4%**。
关键在于：这个优势**几乎不随参数变化**——它不是拟合出的偶然，而是择时机制的结构性结果
（趋势跟随天然会在下跌段空仓）。而收益端恰好相反：牛市（2020–2021）全面跑输，
熊市（2022–2023）才反超。**它卖的是保险，不是收益。**

#### 5. 这份结论的局限（我清楚自己没做到什么）
- 样本是 **20 只"今天还活着"的大盘股**，存在幸存者偏差；未含小盘、退市、ST 标的。
- 区间仅 2020–2023（一轮牛熊），**不足以覆盖所有市场状态**（如 2014–2015 杠杆牛、长期震荡市）。
- 只检验双均线一族，未与动量、反转、多因子等策略对比；因此不能断言"择时无效"，
  只能说"这一族在此样本上没有稳定 alpha"。
- **横截面不独立**：20 只标的策略收益平均相关 ρ̄≈0.18，等效独立样本仅约 4.5 只。
  所有基于"20 个独立配对"的 p 值都偏乐观，Phase 7 已给出修正后的保守 p（详见上节）。
- **资金/整手假设偏乐观**：默认允许小数股、初始资金 10 万。真实 A 股最小 1 手（100 股），
  茅台 10 万本金连一手都买不起——Phase 8 实测该标的入场次数从 28 次被压到 1 次、
  年化由 +10.94% 变为 ≈0%。结论对**低价股基本稳健**，但对高价股必须单独说明。
- **前复权基准会漂移**：qfq 以"拉取时刻最新价"为基准，同一区间在不同时间重拉，历史价格会变。
  仓库内种子数据是随代码分发的固定快照（快照日 **2026-10-31**），论文引用须注明日期。
  注意：种子缓存**故意不写 `.meta.json`**——没有元数据即视为"不过期"，避免 Cloud 每次
  启动都尝试联网刷新（海外网络下会拖慢甚至报错）。自己新拉的数据才有 meta。
- 未建模涨跌停、停牌与流动性冲击；滑点用固定比例近似，未刻画冲击成本。
- ~~p 值用正态近似~~（**已于 2026-11-03 修正**：统一改为 t 分布，n=20 时 df=19；
  口径 B 用 df≈3.5。旧的"正态近似"在本样本下会低估 p 值——这是当时的一个真错误，不是取舍。
  但即使换成更宽松的朴素 t，修正相关性后仍不显著，结论方向未变）。

#### 6. 为什么"没做出 alpha"反而是这段经历的价值
一条漂亮曲线几乎证明不了任何事——**任何人都能调参数调出漂亮曲线**。
能说清"我怎么知道自己错了""结论在什么条件下会失效"，才是研究能力本身。
所以这个项目的最终产出不是一条能赚钱的策略，而是一套**可复用的、能自我证伪的验证流程**：
换策略、换标的、换区间，同一套检验可以直接重跑。

### 稳健性检验（Phase 5–8）：主动找自己的漏洞

这一组脚本的共同目的不是"让结论更好看"，而是**主动攻击自己的结论**，看它在哪里塌。

- `src/phase5_ff3.py` —— **Fama-French 风格三因子归因**（Mkt-Rf / SMB / HML，Newey-West 稳健标准误）：
  等权组合样本内 α=**1.60%**（`p=0.674`）、样本外 α=1.06%（`p=0.780`），均不显著；
  且 20 只个股中"α 在 5% 显著"的**各只有 1 只（1/20 = 5%）**——与"纯随机下期望 5%"完全一致，
  即找不到系统性超额收益的证据。HML 用「国证价值 − 国证成长」风格指数代理。
- `src/phase6_cost_robust.py` —— **真实交易成本稳健性**（佣金万5 + 滑点 0.1% + 印花税 + 过户费）：
  | 指标 | simple（单边万5） | realistic（全成本） |
  |---|---|---|
  | 个股年化均值 | −5.14% | **−7.32%**（平均侵蚀 2.18pp） |
  | 等权组合年化 | −4.07% | −6.26% |
  | CAPM 回归截距 α 均值 | +1.67% | **−0.66%** |
  | α<0 的标的数 | 10/20 | **12/20** |
  → 成本把本就很薄的"超额"吃干，**"无稳定 alpha"的结论在真实成本下更稳**。
  印花税已按 **2023-08-28** 分界动态取 0.1%/0.05%（此前版本全程 0.05%，会低估前半段成本）。
- `src/phase7_robust_se.py` —— **横截面相关性修正**（本项目方法论的最后一环）：
  给出"朴素 p → 有效样本量折算 p → 组合层面分块 bootstrap p"三种口径，
  结论见上文 Phase 3 节。**只报最有利的那个口径 = 学术不诚实**，所以三个一起报。
- `src/phase8_lot_robust.py` —— **A 股整手（100 股）约束**：
  | 口径 | 组合年化 | 夏普 | 最大回撤 |
  |---|---|---|---|
  | A 小数股 + 10 万（论文口径） | −4.06% | −0.38 | −19.80% |
  | B 整手 + 10 万（真实小散户） | −4.64% | −0.49 | −19.73% |
  | C 整手 + 100 万（消除资金约束） | −4.06% | −0.39 | −19.70% |
  → 整手约束的杀伤力**集中而非平均**：19 只低价股几乎无感，茅台则被彻底卡死
  （入场 28→1 次、年化 +10.94%→≈0%）。"回测能跑"≠"账户能跑"。

> 这四步合起来说明一件事：**结论的强度来自"我知道它在什么条件下会失效"**，
> 而不是来自某条好看的净值曲线。

  *Advanced settings* 里把 Python version 选为 **3.13**，否则构建失败。
- **依赖可复现**：`requirements.txt` 已固定为本地验证通过的版本组合（akshare 1.20.18 /
  pandas 3.1.0 / plotly 7.1.0 / backtrader 1.9.78.123 / streamlit 1.66.1 /
  numpy 2.5.4 / statsmodels 0.15.0）。`statsmodels` 是 Phase 5 三因子回归的依赖，
  之前漏声明会导致别人 clone 后跑三因子直接 `ImportError`。
- **不要关 CORS**：`.streamlit/config.toml` 里刻意**没有** `enableCORS=false`。
  关掉它会让任意站点都能与本应用建立 WebSocket 连接（Streamlit 启动时会刷警告），
  公网部署必须保持默认开启。
- **离线可完整演示**：仓库内置 13 只标的（2020–2023，含 3 只 ETF）+ 沪深300 指数，共 **14 个种子缓存**。
  Cloud 服务器在海外、实时抓国内行情易失败，但有缓存时 K线 / 回测 / Beta / Alpha 全部正常，
  已通过「断网 socket 屏蔽」实测验证。
- **数据快照**：种子缓存的快照日为 **2026-10-31**；新拉取的数据会在 CSV 旁生成
  `.meta.json`（记录 fetched_at / 数据源 / 行数 / 价格指纹），网页顶部会显示"数据快照"。
  仓库自带的种子缓存**没有** meta（= 视为固定快照、不参与 30 天 TTL 刷新），这是有意设计。
  前复权以最新价为基准，**换时间重拉同一区间，历史价格会变**——论文引用必须注明快照日。
- **缓存时效**：磁盘缓存默认 30 天过期，过期自动尝试刷新；**刷新失败会回退旧缓存并提示**，
  不会因为海外网络/限流导致白屏。想严格复现论文数字时用 `max_age_days=None` 锁定快照。
- 未纳入缓存的代码或区间会尝试实时抓取，海外网络下可能失败；**演示优先用预置股票 + 2020–2023 区间**。
- 免费版闲置会自动休眠，首次访问冷启动约 30–60 秒，属正常现象。
- 本地演示建议先跑 `python warm_cache.py`（或双击 `run_app.bat`）预热缓存，断网也能出图。
