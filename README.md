# A股/基金量化分析项目 (A-Share & Fund Quant Project)

> 一个面向简历的、可增量推进的金融数据分析与量化回测项目。
> A resume-oriented, incrementally-built financial data analysis & backtest project.

## 项目目标 (Goal)
通过 GitHub 持续提交，复现一项能写进简历的量化/数据分析项目：
从「数据获取 + 可视化」起步，逐步过渡到「经典策略回测」，最终封装为可演示的网页应用。

## 技术栈 (Tech Stack)
- Python 3.13
- `akshare` —— A股/基金行情数据获取
- `pandas` —— 数据清洗与处理
- `plotly` —— 交互式可视化（K线、收益曲线）
- `backtrader` —— 量化策略回测
- `streamlit` —— 最终网页交付

## 推进路线 (Roadmap)
| 阶段 Phase | 内容 | 产出 |
|---|---|---|
| Phase 0 | 环境搭建 + Git/GitHub + 本仓库 | 第一个 commit |
| Phase 1 | 数据获取 + 清洗 + 可视化 | K线/均线图表 |
| **Phase 2** | **经典策略复现 + 回测** | **绩效报告（年化/夏普/回撤）** |
| **Phase 3** | **Streamlit 网页（数据+可视化+回测一体演示）** | **可交互 Demo（面试可现场演示）** |

## Phase 1 成果：数据获取 + 可视化 (Current)
- `src/phase1_fetch.py` —— 拉取单只 A股日线行情存 CSV（基础版，写死茅台）。
- `src/phase1_plot.py` —— 把 CSV 画成可交互 K线图（基础版）。
- `src/phase1_kline.py` —— **增强版工具**：命令行切换任意 A股个股或场内 ETF 基金代码，自动叠加 MA5/MA20 均线（数据层按代码前缀自动识别股票/基金并切换数据源）。
  ```bash
  python src/phase1_kline.py --symbol 600519 --start 20230101 --end 20231231
  python src/phase1_kline.py --symbol 000001 --start 20230101 --end 20231231
  ```
  - 东方财富限流时自动回退新浪数据源（工程容错实践）。
  - 生成的图表（如 `data/kline_600519.html`）被 `.gitignore` 忽略，不进仓库。

## Phase 2 成果：双均线策略回测 (Current)
- `src/data_utils.py` —— 抽离的公共数据层（取数 + 算均线），Phase 1/2 共用；按代码前缀自动识别 **A股个股 / 场内 ETF 基金**并切换数据源（东方财富股票/ETF 接口 + 股票限流回退新浪）。
- `src/phase2_backtest.py` —— 基于 `backtrader` 的 **MA5/MA20 双均线金叉死叉策略**回测：
  - 金叉买入、死叉清仓，`PercentSizer` 满仓、`commission` 万 5 手续费。
  - 输出三大量化指标（均按公式手动计算，并与 backtrader 内置分析器交叉验证）：
    **年化收益、夏普比率、最大回撤**。
  - 自动与「买入持有」对比，判断策略是否跑出超额。
  ```bash
  python src/phase2_backtest.py --symbol 600519  --start 20200101 --end 20231231   # A股个股
  python src/phase2_backtest.py --symbol 510300  --start 20200101 --end 20231231   # 场内 ETF 基金
  ```
- 示例结果（茅台 2020–2023，970 个交易日）：策略年化 **15.41%** / 夏普 0.80 / 回撤 **−19.53%**；
  买入持有年化 13.73% / 夏普 0.58 / 回撤 −47.04% —— 策略以更小回撤跑赢基准。
  （单标的单周期，结论需更多样本验证；数据源限流时会自动回退、复权口径略有差异，
  重跑可能有小数点级偏差，切勿当作投资建议。）
- `src/phase2_batch.py` —— **多股票批量回测**（覆盖 8 只跨行业大盘股）：
  - 统计"策略跑赢买入持有的胜率"与平均绩效，避免单标的幸存者偏差。
  - 8 只样本（2020–2023，含 2022 熊市）结果：**胜率 50%**；策略平均年化 **−2.83%** vs
    持有 −3.23%，平均夏普 **−0.10** vs 0.04，但**平均最大回撤 −37.10% vs 持有 −52.47%**
    —— 即收益端没有稳定优势（胜率仅半数、平均夏普反而更低），却显著压低了回撤。
  - 结论：双均线更像是"风险控制工具"而非"收益增强工具"，需更多样本/参数与
    不同市场环境下验证，切勿当作投资建议。
- `src/phase2_deepen.py` —— **Phase 2 深化**（更大样本 + 参数敏感性 + 显著性检验）：
  - 样本扩至 **20 只跨行业大盘股 × 8 组 (快/慢线) 参数网格**（2020–2023）。
  - 方法严谨：所有参数组在**统一评估窗口**（剔除最大慢线预热期）上比较，
    保证买入持有基准口径一致、跨参数可比。
  - 参数敏感性：胜率 **40%~75%**；慢线 ≤60 的组合平均超额为正（+2.27%~+3.95%），
    慢线=120 的组合全部转负（−1.1%~−1.7%）；
    **所有参数下策略平均最大回撤 −32.8%~−37.6%，显著低于买入持有（−51.4%）**。
  - 统计显著性：默认 MA5/20 超额年化均值 +2.27%，单样本 t 检验
    `t=1.20, p=0.231` → **无法拒绝"无超额收益"的原假设**（经 BH 多重检验校正后 q=0.370，更不显著）。
  - 样本外验证：IS(2020–2021) 最优参数 MA10/20 的超额本身为 **−0.57%**（`p=0.870`），
    OOS(2022–2023) 同组合 **+2.34%**（`p=0.409`）——方向与"熊市保护"一致，但两段均不显著。
  - 结论：双均线策略**没有稳定的收益 alpha，核心价值是风险控制（压低回撤）**；
    该结论本身即体现回测的严谨性，而非过度拟合的"漂亮曲线"。

### Phase 2 方法论说明：这条回测曲线凭什么可信

> 这一节写给"不看代码、只看结论"的读者（面试老师 / 导师）。
> 它讲的不是"我跑了什么策略"，而是**我怎么判断这条曲线是真的，还是回测幻觉**。
> 下文数字均可由 `python src/phase2_deepen.py` 复现（数据源限流时会自动回退新浪，复权口径差异可能带来小数点级偏差）。

#### 1. 先把问题写成可证伪的形式
原假设 **H₀：双均线择时相对买入持有没有稳定的年化超额收益**。

| 检验 | 结果 | 读法 |
|---|---|---|
| 默认参数 MA5/20 | 平均超额年化 **+2.27%**，`t=1.20, p=0.231` | 无法拒绝 H₀ |
| 8 组参数 BH-FDR 校正 | 最优 (5,60) 原始 `p=0.063` → 校正 **`q=0.303`** | 挑出来的"最优"也不显著 |
| 样本外 walk-forward | IS 最优 MA10/20 超额 **−0.57%**（`p=0.870`）→ OOS **+2.34%**（`p=0.409`） | 符号与"熊市保护"一致，但两段都不显著 |

→ 于是结论只能写成：**没有稳定收益 alpha**；而不是"我的策略年化 X%"。

#### 2. 回测最容易骗人的六个地方，以及我分别怎么堵

| 自欺陷阱 | 典型表现 | 本项目的处理 |
|---|---|---|
| 单标的、单周期 | 挑一只走运的股票，曲线很漂亮 | 20 只跨行业大盘股（消费/金融/医药/能源/地产/公用/科技），同区间比较 |
| 参数挑完再报 p 值（data snooping） | 8 组里挑最好的一组做检验，p 值必然偏小 | 对 8 个 p 值做 Benjamini–Hochberg FDR 校正，报 **q 值**而非 p 值 |
| 样本内拟合 | 用同一段数据既选参又验证 | walk-forward：IS 选参 → OOS 只做检验，看衰减与符号是否反转 |
| 基准口径漂移 | 慢线越长，策略可交易起点越晚；买入持有却从第一天算，跨参数不可比 | `warmup=120`：策略与基准都截到第 120 个交易日，**完全同一窗口** |
| 只跟自己比、不跟市场比 | 跑赢个股 ≠ 有 alpha，可能只是承担了更多 Beta | 沪深300 基准 + CAPM 近似 `α ≈ 年化 − β × 指数年化`，只有 α>0 才算真超额 |
| 零成本、指标自说自话 | 忽略佣金；指标公式无人核对 | 单边万 5 佣金、95% 仓位；年化/夏普/回撤**手算 + backtrader 分析器交叉验证** |

#### 3. 三个指标的口径（被追问要能当场推）
- 年化收益 `(1+总收益)^(252/n) − 1`
- 夏普比率 `日均收益 / 日收益标准差 × √252`（无风险利率取 0，A股常用近似）
- 最大回撤 `min(净值 / 历史峰值 − 1)`，回答"最惨会亏多少"

#### 4. 真正的发现：价值在回撤，不在收益
8 组参数下，策略平均最大回撤稳定落在 **−32.8% ~ −37.6%**，同期买入持有 **−51.4%**。
关键在于：这个优势**几乎不随参数变化**——它不是拟合出的偶然，而是择时机制的结构性结果
（趋势跟随天然会在下跌段空仓）。而收益端恰好相反：牛市（2020–2021）全面跑输，
熊市（2022–2023）才反超。**它卖的是保险，不是收益。**

#### 5. 这份结论的局限（我清楚自己没做到什么）
- 样本是 **20 只"今天还活着"的大盘股**，存在幸存者偏差；未含小盘、退市、ST 标的。
- 区间仅 2020–2023（一轮牛熊），**不足以覆盖所有市场状态**（如 2014–2015 杠杆牛、长期震荡市）。
- 只检验双均线一族，未与动量、反转、多因子等策略对比；因此不能断言"择时无效"，
  只能说"这一族在此样本上没有稳定 alpha"。
- 未建模滑点、涨跌停、停牌与流动性冲击；真实成本只会进一步侵蚀收益。
- p 值用正态近似（n=20），仅作量级参考，非精确推断。

#### 6. 为什么"没做出 alpha"反而是这段经历的价值
一条漂亮曲线几乎证明不了任何事——**任何人都能调参数调出漂亮曲线**。
能说清"我怎么知道自己错了""结论在什么条件下会失效"，才是研究能力本身。
所以这个项目的最终产出不是一条能赚钱的策略，而是一套**可复用的、能自我证伪的验证流程**：
换策略、换标的、换区间，同一套检验可以直接重跑。

### 多标的策略验证与可视化报告（Multi-Asset Validation）
- `src/multi_asset_validation.py` —— 对一篮子标的批量回测**双均线择时**策略，按
  **最大回撤（风险控制）** 排序，生成可交互 HTML 报告（排名表 + K线 + 资金曲线 + Top3 叠加）。
- 复用 `data_utils` / `phase2_backtest` / `viz` 公共层，**不重复造轮子**；支持命令行换池 / 换参重跑：
  ```bash
  python src/multi_asset_validation.py
  python src/multi_asset_validation.py --symbols 600519,000001,510300 --start 20230101 --end 20251231
  ```
- 结论：双均线无稳定收益 alpha，核心价值是压低回撤（详见 Phase 2 深化与样本外验证）。

## Phase 3 成果：可交互 Web 应用（面试可现场演示）
- `app.py`（仓库根目录入口）+ `src/viz.py`（统一 K线/均线画图，Phase 1 命令行与网页共用）：
  - 侧栏选择预设股票，或手动输入任意 **A股个股 / 场内 ETF 基金**代码（如 510300） / 设置日期区间 / 调节快线·慢线周期；
  - 主区输出 **K线 + 均线图**、**双均线策略回测绩效**（年化 / 夏普 / 最大回撤，与买入持有对比）、
    **沪深300 指数基准（Beta / 年化 Alpha）**、**策略 vs 买入持有资金曲线**；
  - 行情带本地缓存、回测结果带 Streamlit 缓存，交互流畅。
- 运行方式：
  ```bash
  pip install -r requirements.txt
  streamlit run app.py
  ```
  浏览器打开提示地址（默认 http://localhost:8501）即可演示。
- 工程价值：把前三个阶段的"代码"封装为"可演示产品"，是简历项目从「能讲」到「能看」的关键一步。
